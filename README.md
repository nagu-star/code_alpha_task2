**Overview:**
This repository contains the Exploratory Data Analysis (EDA) for the book dataset scraped in Task 1. The goal was to explore the 
data structure, identify trends,detect anomalies, and prepare the dataset for further analysis.

**Key Steps & AnalysisData:**

Cleaning: Cleaned currency symbols from prices, mapped text ratings to numeric values, and handled missing descriptions.
Data Structuring: Dropped zero-variation columns to streamline the dataset.  
Visualizing Trends: Plotted the distribution of book prices and star ratings. 
Hypothesis Testing: Compared price distributions across different rating tiers using boxplots.
Anomaly Detection: Identified extreme price outliers (the cheapest and most expensive books) using the Interquartile Range (IQR) method.
